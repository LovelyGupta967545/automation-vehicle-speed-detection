Smart Automated Vehicle Counting & Speed Detection System

Ye ek AI-powered traffic analytics system hai jo YOLOv8 (object detection), ByteTrack (multi-object tracking), aur Flask (web streaming) ka use karke real-time mein vehicles ko detect, classify (car/bus/truck/motorcycle), count, aur unki speed calculate karta hai — bina kisi naye hardware sensor ke, seedha existing CCTV footage se.

How It Works — 3 Stages

  1. Detection — YOLOv8 har frame mein vehicles ko bounding box ke saath detect karta hai.
  2. Tracking & Speed — ByteTrack har vehicle ko Unique ID deta hai; perspective calibration (pixel-to-meter conversion) se speed (km/h) nikaali jaati hai, aur counting line se IN/OUT track hota hai.
  3. Web Output — Poora data ek live Flask dashboard par stream hota hai — video feed, counters, aur over-speed alerts ke saath.

Project Structure & File Roles

config/settings.py

Poore project ki central configuration file. Isme ye sab define hai: VIDEO_SOURCE (input video path), MODEL_PATH (YOLOv8 weights), CONFIDENCE_THRESHOLD aur IOU_THRESHOLD (detection filtering), VEHICLE_CLASS_IDS (COCO dataset ke IDs — car/motorcycle/bus/truck), SOURCE aur TARGET (perspective calibration ke liye pixel-to-meter mapping points), LINE_START/LINE_END (counting line ke coordinates), aur SPEED_LIMIT_KMH (over-speed alert threshold). Baaki saari files yahi se apni values leti hain — isliye ek hi jagah change karke poora system tune kiya ja sakta hai.

src/detector.py — Stage 1: Detection

Detector class YOLOv8 model ko wrap karti hai. __init__ mein model ek hi baar load hota hai (taaki har frame par dobara load na karna pade — jo bahut slow hota). detect(frame) method har frame par YOLOv8 chalata hai (confidence/IOU/classes filter ke saath), aur result ko supervision library ke clean Detections format mein convert karke return karta hai — taaki aage tracking mein use karna aasan ho.

src/speed_estimator.py — Stage 2 (Math half)

Do classes hain: ViewTransformer — OpenCV ke getPerspectiveTransform/perspectiveTransform se pixel coordinates ko real-world meters mein convert karta hai (SOURCE aur TARGET points ke beech ek homography matrix banake). SpeedEstimator — har vehicle (uski Unique ID se) ka position-history (time + real-world coordinates) store karta hai; jab kaafi samples ho jaate hain, purani aur nayi position ke beech ka Euclidean distance nikaal ke, time se divide karke, aur ×3.6 karke speed (km/h) calculate karta hai.

src/tracker.py — Stage 2 (Tracking half) — System ka Core

VehicleAnalyzer class — ye poore pipeline ko jodti hai. Iske andar Detector, ByteTrack (sv.ByteTrack()), aur SpeedEstimator teeno ek saath kaam karte hain. process_frame(frame, video_time) method: (1) frame par detection chalata hai, (2) ByteTrack se har detection ko Unique ID deta hai (update_with_detections), (3) har vehicle ka speed nikaalta hai (SpeedEstimator.update), (4) custom labels banata hai (#ID vehicle_type XX.Xkm/h), (5) LineZone se IN/OUT counting karta hai jab vehicle counting-line cross kare, aur (6) frame par boxes/labels/line draw karke annotated frame + stats (in_count, out_count) return karta hai.

src/utils.py

Do chhote helper functions: encode_jpeg(frame) — OpenCV ke cv2.imencode() se frame ko JPEG bytes mein convert karta hai (MJPEG streaming ke liye zaroori). class_name(class_id) — numeric class ID (jaise 2) ko readable naam ("car") mein convert karta hai, config.py ke CLASS_NAME_MAP se lookup karke.

src/__init__.py

src folder ko ek Python package banata hai, aur shortcut imports provide karta hai — taaki app.py mein from src import VehicleAnalyzer, encode_jpeg jaisa simple import likha ja sake, lambe paths ki jagah.

app.py — Stage 3: Web Output (Entry Point)

Poore system ka Flask backend, jisse app run hota hai (python app.py). generate_frames() — ek generator function jo video ko OpenCV se frame-by-frame padhta hai, har frame ko VehicleAnalyzer.process_frame() se process karwata hai, aur result ko JPEG mein encode karke MJPEG stream ke through continuously yield karta hai. Routes: / (dashboard HTML), /video_feed (live MJPEG stream), /stats (JSON mein latest IN/OUT counts, JavaScript isko har second poochta hai), /about (ye page). Ek threading.Lock use hota hai taaki video-processing thread aur web-request thread ek saath safely latest_stats ko access kar sakein.

templates/ & static/

templates/index.html — Live dashboard: <img> tag se video stream dikhata hai (/video_feed ko point karke), aur ek JavaScript function (refreshStats()) har 1 second mein /stats se latest counts leke IN/OUT numbers update karta hai — bina page reload kiye. static/css/style.css aur static/js/ — dashboard ki styling aur baaki interactive behavior.

Tech Stack

  • Python 3.14
  • YOLOv8 (Ultralytics) — Object Detection
  • ByteTrack / Supervision — Multi-Object Tracking
  • OpenCV — Video/Frame Processing
  • Flask — Web Backend & MJPEG Streaming
  • HTML / CSS / JavaScript — Dashboard Frontend

Key Highlights

  • Zero extra hardware cost — existing CCTV se hi kaam karta hai
  • Real-time processing (30+ FPS)
  • Automated vehicle classification, counting, aur speed detection
  • Live web-accessible dashboard

Known Limitations

  • Speed accuracy camera-specific calibration (SOURCE/TARGET) par depend karti hai
  • Dense traffic mein occlusion se tracking mein dikkat aa sakti hai
  • Real-time performance ke liye GPU (CUDA) recommended hai
